# 小鑫英语机 · 使用说明

> 设备：ESP-VoCat（ESP32-S3）｜大脑：家里那台台式机（`192.168.1.10`）｜更新：2026-11-09
> 给家长看的完整版；最后一节是贴墙上给孩子的口令卡。

---

## 一、开机与唤醒

1. 插上电源（5V/2A，别用电脑 USB 口长期供电），约 10 秒开机，屏幕出现文字。
2. 喊 **「你好小鑫」** —— 这是最快的一条路（设备本地识别，约 0.2 秒）。
   也可以喊「嗨小鑫」「小鑫同学」「哈喽小鑫」（约 0.6 秒，稍慢一点）。
3. 唤醒后直接说要做什么，不用等它问。
4. 不说话超过 2 分钟，它会自动断开（下次还要重新唤醒）。
5. **想让它闭嘴**：直接喊「你好小鑫」即可打断；或说「退下」「拜拜」。

> 喊不醒优先用「你好小鑫」四个字，说清楚、别含糊，距离 1 米内。

## 二、能做什么（口令表）

| 你说 | 它做什么 | 大约多久 |
|---|---|---|
| 播放 3-3 第15课课文 | 播这一篇课文 | 1.5 分钟 |
| 播放 3-2 第七单元单词 | 播这个单元的 Key Words | 25 秒 |
| **跟读 3-3 U15** | 逐句跟读：播一句 → 停下等你读 → 判定 | 10~15 分钟 |
| **熟听 3-3** | Smart Reading 3-3：三个单元，每个两遍，下次自动往前滑 | 8.6 分钟 |
| **熟听 POWER UP 1** | POWER UP 1 级：一个单元的故事＋歌曲＋文学，各两遍，下次滑到下一单元 | 10 分钟 |
| 循环播放 3-3 课文 | 整册 16 篇连着播 | 23 分钟 |
| 循环播放 3-3 课文 两遍 | 连播两遍 | 46 分钟 |
| 播放 P1-03 | 按编号点播单条（POWER UP 目前要用编号） | 1.5 分钟 |
| 音量调到 30 | 调音量（0~100） | — |
| 今天天气怎么样 / 现在几点 | 一般问答 | — |

跟读模式里还能说：**「再读一次」**（重播这句）、**「不读了」**（退出跟读）。

## 三、熟听怎么用（每天的主力）

**核心原则：先精听，再熟听。** 没跟他精读过的单元拿来当背景音，等于白噪音。

### 两种素材

| 素材 | 说什么 | 每次内容 |
|---|---|---|
| Smart Reading 3-1 / 3-2 / 3-3 | 熟听 3-3 | 3 个单元 × 2 遍（会重叠复现，重复次数够） |
| POWER UP 1 级 | 熟听 POWER UP 1 | 1 个单元：故事 → 歌曲 → 文学，各 2 遍 |

### 进度会自己记

- 每次说完就前进一格，**下次接着上次**，不用你记。
- 走到最后会说「这册已经听完了，要重头来一遍吗」——回「重头」就从头开始。
- 想跳到某一课：「从 3-3 U5 开始熟听」。

### 建议节奏

- 每天 **1 次、10 分钟左右**，固定时段（比如晚饭后）。
- 音量压到「能听清人说话」以下，环境别有人聊天——太吵等于白放。
- 周末想多听，用「循环播放 3-3 课文」。

### 看记录（家长用）

| 文件 | 内容 |
|---|---|
| `G:\xiaozhi-server\data\review_progress.json` | 每套素材当前进度 |
| `G:\xiaozhi-server\data\play_history.jsonl` | 每次播放的时间、单元、文件名、遍数 |

## 四、屏幕

- 用的是**文字气泡**（不是表情脸）：你说的话在右边（绿色），小鑫的话在左边（灰色）。
- 跟读时屏幕会显示这一句英文。
- 屏幕小、字少，属于正常；主要靠听。

## 五、常见问题

| 现象 | 多半是 | 怎么办 |
|---|---|---|
| 喊不醒 | 声音小/说太快/环境吵/离得远 | 靠近到 1 米，用「你好小鑫」，正常语速 |
| 说一半就被打断 | 停顿被判成"说完了" | 已把静音阈值调到 800ms；仍发生就把句子说完整一点 |
| 完全没反应、屏幕也不亮 | 没电/死机 | 拔电重插 |
| 提示配网、出现 `Xiaozhi-F4FD` 热点 | WiFi 断了或换过路由器 | 手机连该热点 → 打开 `192.168.4.1` → 重填 WiFi（必须 2.4G） |
| 说"未连接服务器" | 电脑关机 / Docker 没起来 | 开机后等 1 分钟；或运行 `docker start xiaozhi-esp32-server` |
| 播不出课文 | 服务端素材目录被改动 | 检查 `G:\xiaozhi-server\data\lessons` |

## 六、家长后台（改东西前先看这节）

**设备只是终端，所有能力都在电脑上的服务端。**

```
G:\xiaozhi-server\
├─ data\.config.yaml          ← 人设、模型、唤醒规则（改完必须重启容器）
├─ data\lessons\              ← 整篇音频（SmartReading1-6、PowerUp1）
├─ data\follow\               ← 跟读用逐句音频 + lesson.json
├─ data\review_progress.json  ← 熟听进度
├─ data\play_history.jsonl    ← 播放历史
└─ plugins_override\          ← 自己写的四个插件
```

常用命令（在这台电脑的终端里）：

```bash
docker ps                                   # 看服务端是否在跑
docker logs -f --tail 50 xiaozhi-esp32-server   # 看实时日志
docker restart xiaozhi-esp32-server         # 改完配置/插件后重启
```

关键地址：

| 项 | 值 |
|---|---|
| 服务端地址 | `ws://192.168.1.10:8000/xiaozhi/v1/` |
| OTA 地址 | `http://192.168.1.10:8003/xiaozhi/ota/` |
| 设备 IP | `192.168.1.16`（DHCP，可能变） |
| 代码与文档 | GitHub `hq7777-bot/kidbox-english` |

**需要找我做的**（自己别动，容易刷坏）：换唤醒词、改固件、加新教材类型。

## 八、当前已知限制（诚实说明）

1. **POWER UP 单条点播只认编号**（`播放 P1-03`）。说「播放 power up 第一单元故事」会被误匹配到 Smart Reading——日常用「熟听 POWER UP 1」即可，不需要单条。
2. **跟读判定是文本相似度**，不是音素级评分；读得含糊可能判不过，连续 2 次会跳下一句，不会卡住。
3. **语音识别对数字不敏感**（"十五"偶尔听成"三五"），说「U15」比说「第十五课」更稳。
4. **唤醒词是固件里写死的**，改名必须重刷固件，没有运行时开关。
