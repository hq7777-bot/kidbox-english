# 逐句跟读：实现说明（v1）

> 对应设计文档 `02_跟读模式设计.md`。这里记录**实际落地**的做法、数据结构和已知问题。

---

## 1. 素材流水线（离线，一次性）

教材自带的音频是**整篇**（Passage 60~90s、KeyWords ~25s），而跟读要求"一句一个文件 + 参考文本"，
所以走三步：

```
整篇 mp3 ──①静音切分──▶ 一句一个 mp3 ──②ASR──▶ raw.json ──③LLM 校对──▶ lesson.json
```

| 步骤 | 脚本 | 产出 |
|---|---|---|
| ① 静音切分 | `tools/split_lessons.py` | `data/follow/SmartReading3/<书>/<Uxx-Passage>/001.mp3…` |
| ② ASR 转写 | `tools/asr_segments.py`（在容器内跑，用 SenseVoice） | 每单元一份 `raw.json` |
| ③ LLM 校对 | `tools/build_lesson_json.py`（宿主机跑，DeepSeek） | 每单元一份 `lesson.json` |

实测规模：**96 个单元 → 1356 句 → 200MB**，全部 LLM 校对成功（0 失败）。

### 关键参数

| 参数 | 值 | 说明 |
|---|---|---|
| 静音判定 | `noise=-35dB, d=0.35s` | 太敏感会切碎，太钝会合并 |
| 最短片段 | 0.60s | 更短的丢弃/合并 |
| 前后留白 | 0.15s | 避免削掉首尾音 |
| ASR 语种 | `en` | 教材是英文；用 en 比 auto 准 |

### 校对为什么必须做

SenseVoice 在英文教材上的典型错误：

| ASR 原始 | LLM 校对后 |
|---|---|
| `Men and Mark are watching TV.` | `Ben and Mark are watching TV.` |
| `Pangguins are so cute.` | `Penguins are so cute.` |
| `But, they can't fly.` | `But they can't fly.` |

校对 prompt 的硬约束：**输出 JSON 数组、长度必须和输入一致、不许合并/拆分句子**，
否则长度对不上会整批落回原始 ASR 文本（脚本里会自动 fallback，并标记 `source: raw`）。

> 踩坑：`deepseek-flash` 是推理模型，不传 `"thinking": {"type": "disabled"}` 时
> 思考 token 会把 `max_tokens` 吃光，返回空 content，表现为 `Expecting value: line 1 column 1`。

## 2. lesson.json 结构

```json
{
  "title": "3-3/U15-Passage",
  "source": "llm",
  "sentences": [
    {"file": "001.mp3", "text": "Cool birds.", "asr_raw": "Cool birds.", "min_score": 0.7},
    {"file": "002.mp3", "text": "Ben and Mark are watching TV.", "asr_raw": "Men and Mark…", "min_score": 0.6}
  ]
}
```

`min_score` 按句长自适应：≤3 词 0.70、≤6 词 0.60、更长 0.50。

## 3. 插件（plugin/follow_reading.py）

注册为工具 `follow_reading`，**必须写进 `Intent.function_call.functions` 白名单**，
否则模型看不到它，只会调 `play_music` 把整篇播出来（这是实际踩到的第一个坑）。

### 动作

| action | 触发 | 行为 |
|---|---|---|
| `start` | 孩子说"跟读 3-3 U15" | 载入 lesson.json，播第 1 句 |
| `check` | 孩子每说一句 | 文本相似度判定 → 通过/重播/跳过 |
| `repeat` | "再读一次" | 重播当前句 |
| `stop` | "不读了" | 清状态，回「拜拜」 |
| `status` | — | 报"第 N 句，共 M 句" |

### 判定规则（v1，纯文本相似度）

```python
score = difflib.SequenceMatcher(None, norm(said), norm(target)).ratio()
```

| 情况 | 处理 |
|---|---|
| `score ≥ min_score` | 说「好」→ 下一句 |
| 不达标 | 说「再读一次」→ 重播 |
| 连续 2 次不达标 | 说「下一个」→ 跳句（不卡住孩子）|
| 最后一句通过 | 说「读完啦」→ 退出 |

### 播报语刻意极简

孩子跟读时不需要"让我们一起聆听"这类话。播报语只有：`好` / `再读一次` / `下一个` / `读完啦` / `拜拜`。

## 4. 已知问题 / 待办

| 项 | 现状 | 下一步 |
|---|---|---|
| **LLM 在环** | v1 每句都要过一次 LLM 路由（+0.5~1s） | v1.5 改成在 `_route_message` 层拦截，跟读模式下不进 LLM |
| **切句质量** | 静音切分约 80~90% 准，存在碎片 | 加"极短段合并"，或人工抽听修正 |
| **断点续跟** | 状态在内存，容器重启即丢 | 落 SQLite，支持"接着跟读" |
| **音素级评分** | 无（只判文本像不像） | v2 接讯飞/微软评测 API |
| **错句复习** | 无 | v3 Leitner 队列 |

## 5. 重新生成素材的命令

```bash
# 1) 切句（宿主机，ffmpeg）
python tools/split_lessons.py --one 3-3/U15-Passage     # 单课试
python tools/split_lessons.py --all                      # 全量

# 2) ASR（容器内，SenseVoice）
docker cp tools/asr_segments.py xiaozhi-esp32-server:/tmp/
docker exec xiaozhi-esp32-server python /tmp/asr_segments.py --all

# 3) LLM 校对 + 生成 lesson.json（宿主机）
set DEEPSEEK_API_KEY=sk-...
python tools/build_lesson_json.py --all

# 4) 挂载插件并重启（改插件/配置后必须重启）
cd G:\xiaozhi-server && docker compose up -d
```
