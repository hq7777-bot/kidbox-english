3. 我们真正的优势（不是自我安慰）

  1. 6 岁孩子不用学操作 听力机要按键选文件、选模式、选速度。我们的入口只有一句话——对不识字的六岁孩子，这是代际差异，不是功能差异。
  2. 任何教材都能进 听力机只认厂商内容包；你手上有 SmartReading、RAZ、牛津树，都能灌。这是"封闭生态 vs 开放库"的区别。
  3. 能对话、能解释 "为什么这里用 is 不用 are"、"patience 什么意思"——听力机答不了。DeepSeek 能，而且用孩子听得懂的话。
  4. 数据在家 录音和对话不出门（ASR 本地、只把文字发给模型）。这点听力机做不到（都要连厂商云）。
  5. 可以长成孩子需要的样子 熟听窗口、整册循环、跟读判定阈值——这些都能改。买来的机器不能。

5. 提升清单（按性价比排序）

P0 — 一周内能做完，体验提升最大

P0-1 字幕同步（孩子跟读时看到句子）

可行性已确认：固件收到 {"type":"tts","state":"sentence_start","text":"..."} 会调用 display->SetChatMessage("assistant", text)（main/application.cc:664）；服务端在 sendAudioMessage() 里正是用 conn.tts.store_tts_text(sentence_id, text) 的内容发这条消息 （core/handle/sendAudioHandle.py:37）。

做法：推每句 FILE 之前，把这一句的英文原文 store_tts_text 进去，而不是只存播报语。 工作量：0.5 天｜验收：跟读时圆屏显示当前句英文，切句时同步变化。

P0-2 变速播放（0.75x / 0.85x）

服务端用 ffmpeg 预生成慢速版本，也可以只在需要时现转（atempo 不改变音高）：

ffmpeg -i 001.mp3 -filter:a "atempo=0.75" -q:a 4 001_slow.mp3

做法：data/follow/.../slow/001.mp3 预生成；工具参数加 speed（0.75/0.85/1.0），播慢速版。 工作量：1 天｜验收：说"慢一点"，同一句以 0.75x 重播。

P0-3 跟读录音回放（听自己 vs 原声）

风险点：需要设备在播放时也开麦（全双工）。他的固件已开 USE_DEVICE_AEC，硬件有回采参考，理论上可以。 做法：跟读模式下把孩子的音频按句存 data/records/<lesson>/<句号>.wav；说"再听一遍我说"时回放。 工作量：1~2 天（含验证）｜验收：孩子跟读后能听到自己的声音。

P1 — 两三天，把"跟读"变成"纠音"

P1-1 口语评测（音素级）

接第三方评测 API（讯飞语音评测 ISE / 微软 Pronunciation Assessment / 阿里）。

  • 输入：孩子这句的 wav + 参考文本
  • 输出：总分、单词级、音素级（th 读成 s 会被指出）
  • 替换现有 difflib 相似度打分，min_score 改为评测分数阈值

工作量：2~3 天｜验收：故意读错一个词，它能指出是哪个词、哪个音。

P1-2 定时 / 睡前模式

"听 20 分钟后停" → 服务端队列加一个定时中断（asyncio.call_later），到点推一句"今天就到这儿"。 工作量：0.5 天｜验收：设 20 分钟，到点自动收尾，不硬切。

P1-3 家长周报（R7）

从 loop_progress.json + 对话日志聚合：

指标 说明
本周听课时长 按册/单元统计
开口率 跟读中"有回应"的比例
错句 Top10 评测分数最低的句子
生词 问过的词 + 读错的词

输出成一段文字推微信，或落 data/reports/2026-W45.md。 工作量：1 天｜验收：每周一早上收到一份。

P2 — 稳定后再做

项 说明 工作量
生词本 + Leitner 复用 kidbox/db.py 已验证的 1/2/4/7/15 天算法 1 天
任意 AB 复读 按秒级切段（ffmpeg -ss -t），比按句更灵活 1 天
离线兜底 固件不读 SD，只能改固件缓存最近一单元 3~5 天，不建议

6. 不建议跟着做的

听力机这么做 我们不要做的原因
屏幕菜单/触屏选课 违背"纯语音"的核心价值，6 岁也不需要
做内容商店/资源库 版权和运营是无底洞，用户自己灌更灵活
内置电池做成便携 便携=要管充电=家长负担；固定位置反而更好用
追音素评测到极致 一年级阶段"敢开口"比"发音标准"重要，评测做到"能指出哪个词"就够

7. 一句话结论

听力机赢在评测、变速、离线、便携这些"成熟硬件功能"； 我们赢在免操作、开放库、能对话、可演进这些"架构能力"。

只要把 字幕、变速、录音回放、口语评测 这四件补齐， 我们在"一年级英语学习"这个具体场景上就会明显超过市面产品—— 因为那四件是功能，而前四条是它们改不了的东西。
