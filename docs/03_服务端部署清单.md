# 服务端部署清单（旧笔记本 · Windows）

> 目标：让旧笔记本变成 VoCat 的"大脑"，能听懂、能回答、能播你的教材音频
> 预计 1~2 小时（下载占大头）｜每一步都有"验收"，过了再往下

---

## 阶段 0：给笔记本做准备（20 分钟）

### 0.1 先确认能不能跑 Docker

- [ ] Win10 2004 以上 或 Win11
- [ ] 任务管理器 → 性能 → CPU，看有没有 **"虚拟化：已启用"**
  - 如果是"已禁用"：进 BIOS 打开 VT-x / SVM（开机按 F2/F10/Del，找 Virtualization）
- [ ] 内存 ≥ 8GB

### 0.2 装 Docker Desktop

- [ ] 下载：<https://www.docker.com/products/docker-desktop/>
- [ ] 安装时勾选 **Use WSL 2 instead of Hyper-V**
- [ ] 装完重启，打开 Docker Desktop，左下角显示 **Engine running** 才算好

验证（开 PowerShell）：

```powershell
docker version
```

看到 Client 和 Server 两段 = 成功。

### 0.3 关掉睡眠（必须）

控制面板 → 电源选项 → 更改计划设置：

- [ ] 关闭显示器：**从不**
- [ ] 使计算机进入睡眠状态：**从不**
- [ ] 更改高级电源设置 → 硬盘 → 在此时间后关闭硬盘：**从不**
- [ ] 选择关闭盖子的功能：**不采取任何操作**

## 阶段 1：建目录（5 分钟）

在你想放的位置（建议 `D:\xiaozhi-server`）建这个结构：

```
D:\xiaozhi-server\
  ├─ docker-compose.yml
  ├─ data\
  │    ├─ .config.yaml
  │    └─ lessons\          ← 你的教材音频放这里
  │         └─ L1\001_hello\001.mp3
  └─ models\
       └─ SenseVoiceSmall\
            └─ model.pt
```

- [ ] 目录建好

> 为什么必须是这个结构：compose 里写死了
> `./data:/opt/xiaozhi-esp32-server/data` 和
> `./models/SenseVoiceSmall/model.pt:/opt/.../model.pt`

## 阶段 2：下载语音识别模型（10~30 分钟，看网速）

- [ ] 下载（约 900MB，魔搭直链，国内快）：
      <https://modelscope.cn/models/iic/SenseVoiceSmall/resolve/master/model.pt>
- [ ] 放到 `D:\xiaozhi-server\models\SenseVoiceSmall\model.pt`

**验收**：文件大小 > 800MB，不是 0KB 的 HTML。

> 百度网盘备用（提取码 qvna）：<https://pan.baidu.com/share/init?surl=QlgM58FHhYv1tFnUT_A8Sg&pwd=qvna>
> 缺这个文件 = 容器起不来，这是最常见的失败原因。

## 阶段 4：改配置（10 分钟，只改 4 处）

用记事本打开 `D:\xiaozhi-server\data\.config.yaml`，找到这几行改：

### ① 换大脑为 DeepSeek

找到 `selected_module:` 段，把 `LLM:` 改成：

```yaml
selected_module:
  VAD: SileroVAD
  ASR: FunASR
  LLM: DeepSeekLLM        # ← 原来是 ChatGLMLLM
  VLLM: ChatGLMVLLM
  TTS: EdgeTTS
  Memory: mem_local_short  # 原来是 nomem，打开短期记忆
  Intent: function_call
```

### ② 填 DeepSeek Key

同一个文件，找 `DeepSeekLLM:` 段：

```yaml
LLM:
  DeepSeekLLM:
    type: openai
    model_name: deepseek-flash        # 官网现名；写 deepseek-v4-flash 也能跑
    url: https://api.deepseek.com
    api_key: sk-你的key               # ← 填这里
```

Key 在 <https://platform.deepseek.com/api_keys> 申请（充 10 块钱就够用很久）。

### ③ 把音乐目录指向你的教材

文件末尾加（如果已有 `plugins:` 就加在它下面）：

```yaml
plugins:
  play_music:
    music_dir: /opt/xiaozhi-esp32-server/data/lessons
    refresh_time: 30
```

**注意是容器内绝对路径**，不是你电脑上的 `D:\...`。

### ④ （可选）改成中文小孩友好的音色

```yaml
TTS:
  EdgeTTS:
    voice: zh-CN-XiaoyiNeural
```

## 阶段 6：启动（5 分钟）

```powershell
cd D:\xiaozhi-server
docker compose up -d
docker logs -f xiaozhi-esp32-server
```

**看到这样的日志 = 成功**（IP 会是你的）：

```
INFO-OTA接口是        http://192.168.1.25:8003/xiaozhi/ota/
INFO-Websocket地址是  ws://192.168.1.25:8000/xiaozhi/v1/
```

按 `Ctrl+C` 退出日志查看（不会停容器）。

**验收**：
```powershell
docker ps
```
看到 `xiaozhi-esp32-server` 状态是 `Up`。

## 阶段 7：放行防火墙 + 记下 IP（5 分钟）

```powershell
# 以管理员身份运行 PowerShell
netsh advfirewall firewall add rule name="xiaozhi" dir=in action=allow protocol=TCP localport=8000,8003

ipconfig
```

- [ ] 记下 `IPv4 地址`，例如 `192.168.1.25`

## 阶段 8：让 VoCat 连过来（5 分钟）

- [ ] 长按 VoCat 的 BOOT 键，进入配网（屏幕/语音会提示）
- [ ] 手机连 `Xiaozhi-XXXX`
- [ ] 浏览器打开 `192.168.4.1`
- [ ] 找 **「高级」** 标签
- [ ] OTA 地址填：`http://192.168.1.25:8003/xiaozhi/ota/`（换成你记下的 IP）
- [ ] 保存 → 设备重启

**验收**：`docker logs -f` 里出现设备连接记录。

## 阶段 9：验收（5 分钟）

对 VoCat 说：

|---|---|---|
| 1 | 你好 | 有回应（DeepSeek 通了） |

## 排错表（按现象查）

| 现象 | 原因 | 处理 |
|---|---|---|
| `docker compose up` 报 mount 错误 | 目录结构不对 | 按阶段 1 的树重建 |
| 容器起来就退出 | **model.pt 没放对** | `docker logs` 会提示；检查是不是 0KB 的 HTML |
| 日志里有 OTA 地址但设备连不上 | 防火墙 / IP 写错 | 阶段 7；确认手机和电脑同一 WiFi |
| 设备连上了，说话没反应 | ASR 模型没加载 | 看日志有没有 FunASR 加载成功 |
| 能对话但不播音乐 | music_dir 路径错 | `docker exec -it xiaozhi-esp32-server ls /opt/xiaozhi-esp32-server/data/lessons` |
| 说"播放 xxx"它说找不到 | 文件名对不上 | 直接把文件名念出来；或改用 `play_lesson` 插件 |
| 声音卡顿 | 笔记本性能不足 / WiFi 差 | 换有线网；ASR 改用云端 |

## 日常维护（记这四条就够）

```powershell
# 看日志
docker logs -f --tail 50 xiaozhi-esp32-server

# 重启
docker restart xiaozhi-esp32-server

# 停 / 起
docker stop xiaozhi-esp32-server
docker start xiaozhi-esp32-server

# 升级（先备份 data\.config.yaml！）
docker compose pull
docker compose up -d
```

- **备份**：`data\.config.yaml` 和 `data\lessons\` 拷一份到别处就行
- **开机自启**：装了 Docker Desktop 并设成开机启动，容器带 `restart: always` 会自动起来
