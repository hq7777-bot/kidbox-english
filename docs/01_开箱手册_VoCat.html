VoCat 开箱手册：从拆箱到孩子能对话

预计 60~90 分钟｜全程不需要写代码｜每一步都有"验收"，过了再往下走 固件版本以本文写作时为准：v2.5.2（2026-10-11）

0. 准备清单

  • [ ] VoCat 主板（V1.0）+ 底座（如果有）
  • [ ] USB-C 数据线（必须能传数据，不能是纯充电线）
  • [ ] 5V/2A 电源（手机充电头就行，别用 PD 快充诱骗器）
  • [ ] 一台 Windows 电脑
  • [ ] 手机（配网用）
  • [ ] 家里 WiFi 密码（必须知道是 2.4G 还是 5G）
  • [ ] 路由器在附近，信号满格

1. 通电自检（5 分钟）

  • [ ] 插上 Type-C 线，看屏幕

验收：屏幕亮，能看到画面（logo 或表情）。

黑屏就先别急着刷机，按这个顺序排：

  1. 换一根线（十有八九是充电线，没有数据线芯）
  2. 换 USB 口，或直接用 5V 电源
  3. 按住 BOOT 键再插线（强制进下载模式，屏幕会保持黑）

2. 确认版本（1 分钟）

  • [ ] 看包装或板子背面丝印，确认是 V1.0

不用管版本差异：当前固件的板级代码里有 DetectPcbVersion()，开机会自动探测 V1.0 / V1.2 并套用对应引脚，串口日志会打印 PCB version V1.0。

3. 下载固件（5 分钟）

  • [ ] 打开 https://github.com/78/xiaozhi-esp32/releases
  • [ ] 找最新的 release（现在 v2.5.2）
  • [ ] 下载 v2.5.2_espressif-esp-vocat.zip（约 2.9 MB）
  • [ ] 解压，里面只有一个文件：merged-binary.bin（约 11.3 MB）

别下成 espressif-esp-box-3——那是 BOX-3 的固件，名字很像。 认准 vocat 这五个字母。

4. 烧录（10 分钟）

先找串口号（Windows）

  • [ ] 插上板子 → 右键"开始"→ 设备管理器 → 端口 (COM 和 LPT)
  • [ ] 记下 COM几（例如 COM5）

看不到端口 = 线是充电线，或者没装驱动（ESP32-S3 一般免驱，Win10 以上自带）。

烧（推荐本地命令行，国内最稳）

pip install esptool

# 把 COM5 换成你实际的端口号
esptool.py --chip esp32s3 -p COM5 -b 460800 write_flash 0x0 merged-binary.bin

看到 Hash of data verified. 就是成功，板子会自动重启。

如果提示 "Failed to connect"

  • [ ] 按住 BOOT 不放，再插 USB，然后松开 BOOT，重跑命令

备选：网页烧录

Chrome / Edge 打开 espressif 的在线烧录页（ESP Launchpad），选 ESP32-S3、端口、地址 0x0、文件选 merged-binary.bin。

验收：烧完板子重启，屏幕亮起，可能播报一串提示（如"请配网"）。

5. 配网（5 分钟）

  • [ ] 手机 WiFi 列表里找 Xiaozhi-XXXX（无密码，开放热点）
  • [ ] 连上它，等自动跳转配置页；不跳就用浏览器输 192.168.4.1
  • [ ] 选你家 WiFi，输密码，点连接
  • [ ] 板子重启并连上网

验收：屏幕/语音提示"已连接"，或设备开始播报 6 位激活码。

配网失败的三个常见原因

现象 原因 处理
列表里搜不到 WiFi 只支持 2.4G 把路由器 2.4G 单独开一个 SSID
输入密码后连不上 连的是 5G 同上
用手机热点连不上 iPhone 默认 5G 开"最大兼容性"

需要网页二次认证的 WiFi（酒店、公司）连不上，别在这上面耗时间，用手机热点或家里的。

6. 激活（5 分钟）

  • [ ] 记下设备播报的 6 位数字（屏幕上也应该有）
  • [ ] 手机或电脑打开 https://xiaozhi.me
  • [ ] 用手机号注册 / 登录
  • [ ] 输入 6 位码 → 添加设备
  • [ ] 设备重启后即可使用

验收：设备能应答"你好，小智"。

6 位码有时效，过期就唤醒设备让它重播一次。注册只支持部分地区手机号（中国大陆可以）。

7. 第一次对话 + 功能验收（10 分钟）

唤醒词默认 "你好，小智"；不应答就试 "Hi ESP"。

对着它说这 7 句，把结果记在右边：

# 你说 预期 实际（打勾/记问题）
1 你好 有回应、表情变化 ☐
2 你叫什么名字 自然对话 ☐
3 讲个睡前故事 生成内容 ☐
4 恐龙为什么灭绝 知识问答（记下答得对不对） ☐
5 （它说话时直接插话） 能被打断 ☐
6 声音小一点 语控设备 ☐
7 你看到我了吗 / 转过来 声源定位（双麦阵列） ☐

这张表就是你后面要补的功能清单。

8. 试一试"它做不到的"（5 分钟）

刻意说这三句，不是故障，是为了让你亲眼看到边界：

  • [ ] "播放第三课" → 大概率不会（它没有你的音频库）
  • [ ] "复习上两个音频" → 不会
  • [ ] "接着上次听" → 不会

看到它答不上来，你才会明白为什么需要自建服务端。

9. 下一步怎么走

情况 下一步
孩子愿意跟它说话，问"它还能干什么" 搭服务端，接 DeepSeek + 教材音频（主文档 §19）
孩子玩两下就丢一边 先停。别急着投入，观察一周再说
唤醒/打断体验很差 先调位置和音量，别急着换硬件——很多是距离和环境噪声问题

常见问题速查

现象 最可能的原因 处理
黑屏 充电线 / 供电不足 / 刷错固件 换数据线、5V2A、确认是 esp-vocat
烧录连不上 没进下载模式 按住 BOOT 插线
屏幕亮但没声音 音量 0 / 喇叭线松 语音调大、按压喇叭座
表情不动只有文字 资源包没烧进去 先确认用的是 release 里的合并固件；仍不行按主文档 §18.4 单独烧资源包
唤醒不灵 环境吵 / 距离远 / 电视在响 1 米内、安静房间再试
说两句就断 WiFi 信号弱 / 路由器省电 靠近路由器；关掉路由器的"节能/绿色模式"
一直重启 供电不足 换 5V/2A，别用电脑 USB 口直供

给孩子用之前的三件事

  • [ ] 音量先调到 50% 以下再给他（对讲机/音箱类设备很容易过响）
  • [ ] 放在桌面，别放床边通宵充（USB 供电会发热）
  • [ ] 先不要做外壳、不要加电池——等确认孩子天天用，再投入
