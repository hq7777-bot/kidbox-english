# 跟读模式设计（ESP-VoCat + 小智自建服务端）

> 目标：一句英文音频 → 播完 → 等孩子跟读 → 判定 → 下一句
> 结论：**能做，不需要本地客户端，不需要改固件。** 缺的只是一个"状态机插件"。

---

## 1. 为什么不用做本地客户端

小智服务端已经具备这件事需要的三样东西，你只缺"逻辑"：

| 需要的能力 | 小智里现成的 | 出处 |
|---|---|---|
| 逐句推音频 | `ContentType.FILE` 一次推一个文件 | `plugins_func/functions/play_music.py` |
| 判断"孩子说完了" | SileroVAD，`max_sentence_silence: 200ms` | `config.yaml` 的 VAD / ASR 段 |
| 拿到"孩子说了什么" | ASR（本地 SenseVoice / 云端） | `config.yaml` 的 selected_module.ASR |
| 触发下一轮 | 播完 TTS，设备自动回到聆听（连续对话） | 固件默认行为，需实测确认 |

**做本地客户端只有三种情况才值得**：
1. 要毫秒级同步的"卡拉OK高亮"；
2. 要完全离线（本地 ASR + 本地 TTS + 本地 LLM）；
3. 用官方服务器（官方不开放工具/状态机入口）。

你三个都不需要，所以方向是：**自建服务端 + 跟读插件**。

## 2. 状态机

```
        孩子说"跟读第三课"
                │
                ▼
        ┌───────────────┐
        │  PLAY_SENTENCE│◀──────────────┐
        │  推第 n 句 mp3 │               │
        └───────┬───────┘               │
                │ TTS 队列清空            │
                ▼                       │
        ┌───────────────┐   超时/没开口   │
        │  WAIT_REPEAT  │───────────────┤
        │ 等孩子跟读     │  重播同一句     │
        └───────┬───────┘  （最多 2 次）  │
                │ 收到 ASR 文本          │
                ▼                       │
        ┌───────────────┐   不达标        │
        │    JUDGE      │───────────────┘
        │ 相似度比对     │
        └───────┬───────┘
                │ 达标
                ▼
        ┌───────────────┐
        │  下一句 / 结束  │
        └───────────────┘
```

**关键设计**：状态机挂在"每轮用户输入到达时"，不依赖"播放结束回调"。

理由：播放结束没有可靠回调，但孩子一开口就必然产生一轮新的用户输入。用"收到输入"驱动，状态机永远往前走，不会卡死。

## 3. 数据结构

`lessons/L1/003_animals/lesson.json`：

```json
{
  "title": "Animals",
  "sentences": [
    {"file": "01.mp3", "text": "Look at the cat.",     "min_score": 0.55},
    {"file": "02.mp3", "text": "The cat is sleeping.", "min_score": 0.55},
    {"file": "03.mp3", "text": "Do you like cats?",    "min_score": 0.50}
  ]
}
```

- `text` 是判定用的参考句，**必须和音频内容一致**；
- `min_score` 按句子长度调：短句容易误判（"Yes." 这类），阈值要高一点；
- 没有 `lesson.json` 就退化成"按目录顺序播"，不做判定。

**一条音频 = 一句话**，这是硬约束（否则没法逐句播）。

## 4. 判定算法（v1，不上评分 API）

```python
import difflib, re

def norm(s):
    s = s.lower().strip()
    s = re.sub(r"[^a-z0-9' ]", "", s)     # 去掉标点
    return re.sub(r"\s+", " ", s)

def score(said, target):
    return difflib.SequenceMatcher(None, norm(said), norm(target)).ratio()
```

判定规则：

| 情况 | 处理 |
|---|---|
| `score ≥ min_score` | 通过 → 夸一句（"很好，下一个"）→ 下一句 |
| `0.3 ≤ score < min_score` | 接近 → 提示具体问题（"cat 再读一次"）→ 重播 |
| `score < 0.3` 且孩子说了中文 | 用中文引导（"跟着我读：Look at the cat"）→ 重播 |
| 8 秒没声音 | 重播一次；连续两次没声音 → 停在这个句子，等孩子说"继续" |
| 连续 2 次不达标 | 直接下一句（不卡住孩子，挫败感比准确性重要） |

**v2 才考虑**：接口语评测 API（讯飞/微软/ELSA）做音素级评分。那需要把孩子的 wav 传给第三方——小智服务端能拿到音频流，但要自己加钩子，工作量 2~3 天。

## 5. 跟读模式下要不要 LLM

**不要，或者只让它说"串场词"。**

理由：
- 判定是确定性逻辑，用 LLM 判会增加 1~2 秒延迟，还可能判错；
- 孩子跟读时说的话很短（"Look at the cat"），LLM 容易过度解读。

实现：插件里加一个"会话模式"标记。处于跟读模式时，**在意图处理层拦截**，不进入 LLM 对话流程；只有孩子说"不读了/换一课/这是啥意思"这类跳出指令时才回到 LLM。

---

## 6. 三个必须接受的限制

| 限制 | 说明 | 缓解 |
|---|---|---|
| **延迟 1~2 秒** | 孩子读完 → ASR → 比对 → 播下一句 | 播下一句前先说一个短词（"嗯"）填空；或用流式 ASR |
| **句子边界要你提供** | 一条音频必须是一句话 | 教材自带逐句音频最好；否则 ffmpeg 静音切分，准确率 80~90%，人工听一遍修 |
| **没有音素级评分** | v1 只判"读得像不像"，不判"th 有没有咬舌" | v2 接评测 API |

## 7. 音频从哪来（三条路）

| 来源 | 做法 | 质量 |
|---|---|---|
| 教材自带逐句音频（RAZ、牛津树部分版本） | 直接用，最省事 | ★★★ |
| 一整段音频 → 自动切分 | `ffmpeg -af silencedetect` 找静音点切，再人工听一遍合并/拆分 | ★★ |
| 只有文字没有音频 | 用 TTS 生成（edge-tts 英文童声 `en-US-AnaNeural`） | ★（不是原声，但可控） |

切分命令示例：

```bash
ffmpeg -i lesson.mp3 -af silencedetect=noise=-35dB:d=0.45 -f null - 2>&1 | grep silence
# 按输出时间点，切成一堆 001.mp3 002.mp3 …
```

## 8. 验收标准（可测）

| # | 场景 | 期望 |
|---|---|---|
| 1 | 说"跟读第三课" | 播第 1 句，播完停住等孩子 |
| 2 | 孩子正确跟读 | ≤ 2 秒内播第 2 句 |
| 3 | 孩子读错 | 重播同一句，并提示哪里不对 |
| 4 | 孩子 8 秒不说话 | 重播一次；再不说话就停住等"继续" |
| 5 | 孩子说"不读了" | 退出跟读，回到普通对话 |
| 6 | 中途断电 | 恢复后能"接着跟读"，从那一句继续 |
| 7 | 连续 2 次读错 | 不卡住，自动进下一句 |

## 9. 迭代路线

| 版本 | 做什么 | 工期 |
|---|---|---|
| **v1** | 逐句播放 + 等待 + 相似度判定 + 重试 | 2~3 天 |
| v1.5 | 进度记录、断点续跟、跟读统计（哪几句老读错） | +1 天 |
| v2 | 接口语评测 API，音素级打分 | +2~3 天 |
| v3 | 错句自动进"复习队列"（Leitner 盒子） | +1 天 |

## 10. 唯一需要先验证的事

**"TTS 播完后，设备是否自动回到聆听状态。"**

- 如果自动回（多数固件默认是连续对话模式）→ 上面的设计直接成立；
- 如果不回 → 服务端在每句后追问一句"该你了，跟着读"，用 LLM 触发下一轮聆听；或者用"句子 + 3 秒静音"拼成一个文件播，走固定节奏。

板子到手后第一件事就是测这个：说一句话，等它说完，然后**不说话**，看它是否继续听你。能继续听 = 设计成立。
